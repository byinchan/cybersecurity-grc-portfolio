## About Pacific Utilities Corporation

Pacific Utilities Corporation (PUC) is a fictional provincial Crown corporation responsible for delivering critical utility services across British Columbia.

PUC operates critical infrastructure supported by enterprise IT and operational technology environments, serving residential, commercial, industrial, and public-sector customers.

> **Note:** PUC is a fictional organization created for educational and portfolio purposes.

## GRC Portfolio Roadmap
